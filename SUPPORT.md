# Support

Thank you for using **Enterprise AI Architecture in C++**.

This document explains how to get help, report problems, and contribute to the project.

---

# Getting Help

Before opening an issue, please check:

* The project README
* Existing GitHub Issues
* Project documentation
* Examples and sample code
* Frequently asked questions (if available)

Many common questions have already been answered.

---

# Bug Reports

If you discover a bug, please open a GitHub Bug Report and include:

* Operating system
* Compiler and version
* CMake version
* Project version
* Steps to reproduce
* Expected behavior
* Actual behavior
* Relevant logs or screenshots

Providing complete information helps us resolve issues more quickly.

---

# Feature Requests

Ideas and suggestions are always welcome.

When submitting a feature request, please describe:

* The problem you are trying to solve
* Your proposed solution
* Alternative approaches considered
* Example use cases

Well-described requests are much easier to evaluate.

---

# Questions

For general questions:

* Search existing Issues and Discussions.
* If your question has not been answered, open a new discussion or issue with sufficient detail.

Please provide enough context so that community members can help effectively.

---

# Contributing

We welcome contributions of all sizes.

Before contributing, please review:

* CONTRIBUTING.md
* CODE_OF_CONDUCT.md
* SECURITY.md

These documents explain our development workflow and community expectations.

---

# Community Expectations

To maintain a welcoming environment, please:

* Be respectful.
* Be constructive.
* Stay on topic.
* Help others learn.
* Assume positive intent.
* Provide actionable feedback.

We value collaboration and professionalism.

---

# Response Times

This is an open-source project maintained by contributors.

While we strive to respond as quickly as possible, response times may vary depending on:

* Issue complexity
* Contributor availability
* Project priorities

We appreciate your patience.

---

# Ways to Help

You can support the project by:

* Reporting bugs
* Improving documentation
* Fixing issues
* Adding tests
* Reviewing pull requests
* Sharing feedback
* Suggesting new features
* Improving performance
* Sponsoring development (if available)

Every contribution helps improve the project.
